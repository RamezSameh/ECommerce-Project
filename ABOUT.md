# About

ECommerce Project is a full-stack e-commerce application designed for learning, portfolio development, and real-world product catalog workflows.

It combines a .NET 8 backend with an Angular frontend, using SQL Server for persistence and Clean Architecture patterns for maintainability.

## Purpose

The project demonstrates a complete online shopping flow, including:

- user authentication and authorization
- product browsing and filtering
- cart and checkout flows
- order tracking
- coupon and payment handling
- admin management tools

## Stack

- ASP.NET Core Web API
- Angular 19
- Entity Framework Core
- SQL Server
- JWT + ASP.NET Identity
- Swagger / OpenAPI
- Docker Compose

## Project Goal

To create a scalable and practical e-commerce platform with a modular architecture that can be extended with new features, integrations, and business logic over time.
